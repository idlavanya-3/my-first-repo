# AWS Services

## EC2
Amazon Elastic Compute Cloud (EC2) provides virtual servers in the cloud.

## S3
Amazon Simple Storage Service (S3) provides secure object storage.

## IAM
Identity and Access Management (IAM) helps manage users, roles, and permissions.

## VPC
Virtual Private Cloud (VPC) provides a private network environment.

## RDS
Relational Database Service (RDS) provides managed databases.
